TROUBLESHOOTING QUICK REFERENCE
================================================================================

ISSUE: Client says "site can't be reached"

SOLUTIONS (in order):
1. Verify Radmin VPN shows "Online"
2. Verify correct IP: 26.29.218.176
3. Try different browser
4. Clear browser cache (Ctrl+Shift+Del)
5. Disconnect/reconnect VPN
6. Restart computer

---

ISSUE: Login doesn't work

SOLUTIONS:
1. Double-check credentials (Caps Lock?)
2. Verify account exists in system
3. Reset password via admin panel
4. Try different browser
5. Clear cookies/cache

---

ISSUE: Page loads very slowly

SOLUTIONS:
1. Check internet speed
2. Try wired connection (faster than WiFi)
3. Close other applications
4. Try during off-peak hours
5. Check VPN network congestion
