================================================================================
TROUBLESHOOTING
================================================================================

PROBLEM: "Connection refused" when accessing http://localhost:8000
FIX:
  1. Check if server is running (RUN_DASHBOARD.bat window should show output)
  2. If not running, double-click RUN_DASHBOARD.bat again
  3. Wait 5-10 seconds for Laravel to start
  4. Refresh browser (Ctrl+F5)

PROBLEM: "Invalid credentials" when logging in
FIX:
  1. Make sure you're using exactly: manager@vss.com / manager123
  2. Check CAPS LOCK is OFF
  3. Password is case-sensitive
  4. Try admin account: admin@vss.com / admin123

PROBLEM: Dashboard blank or charts not showing
FIX:
  1. Open browser Developer Console (F12)
  2. Check for errors (should be none)
  3. Refresh page (Ctrl+F5)
  4. Check database: php artisan migrate:status (should show all migrated)

PROBLEM: "Logout" button not working
FIX:
  1. Make sure you're on a HTTPS page (not HTTP)
  2. Try clearing browser cookies
  3. Close browser completely and reopen

PROBLEM: Server won't start - "Port 8000 already in use"
FIX:
  1. Another process is using port 8000
  2. Kill it: netstat -ano | findstr :8000
  3. taskkill /PID <PID_NUMBER> /F
  4. Try starting server again

PROBLEM: "Class not found" or "Migration error"
FIX:
  1. Run: C:\laragon\bin\php\php-8.1.10-Win32-vs16-x64\php.exe artisan migrate:fresh --seed
  2. This will recreate database from scratch
  3. Re-run RUN_DASHBOARD.bat
