TROUBLESHOOTING
───────────────

Problem: "MySQL port already in use" atau "Port 3306 in use"
Solution:
  1. Laragon mungkin sudah running
  2. Buka Laragon tray icon
  3. Stop services → Start services lagi
  4. Atau restart Laragon completely

Problem: "php.exe not found"
Solution:
  1. Ensure Laragon is installed at C:\laragon
  2. Verify C:\laragon\bin\php exists
  3. If not, reinstall Laragon

Problem: "Connection refused" atau "Cannot connect to database"
Solution:
  1. Make sure Laragon MySQL is running (green icon)
  2. Check .env file:
     DB_HOST=127.0.0.1
     DB_PORT=3306
     DB_USERNAME=root
     DB_PASSWORD=

Problem: Port 8000 already in use
Solution:
  Use different port:
  "C:\laragon\bin\php\php-8.1.10-Win32-vs16-x64\php.exe" artisan serve --port=3001
