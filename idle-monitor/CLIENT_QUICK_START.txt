================================================================================
TROUBLESHOOTING
================================================================================

PROBLEM: "This site can't be reached"

CHECK:
☐ Radmin VPN is open?
☐ Status shows "Online"?
☐ IP is correct: 26.29.218.176
☐ Port is correct: 8000
☐ Internet is working (try Google)?

SOLUTIONS:
1. Disconnect/Reconnect VPN
2. Refresh browser page (F5)
3. Try different browser
4. Restart Radmin VPN
5. Clear browser cache (Ctrl+Shift+Del)
6. Wait 30 seconds, try again

---

PROBLEM: Login doesn't work

CHECK:
☐ Caps Lock is OFF?
☐ Username correct?
☐ Password correct?
☐ No extra spaces?

SOLUTIONS:
1. Try again (carefully type)
2. Ask admin to reset password
3. Use "Forgot Password" link
4. Check credentials are correct

---

PROBLEM: Page loads very slowly

SOLUTIONS:
1. Check internet speed (speedtest.net)
2. Close other applications
3. Disconnect other devices from WiFi
4. Try wired connection instead
5. Try later (network might be busy)
