PROBLEM:
- Chevron arrow didn't rotate when clicking
- Groups (BUS - GPE, DT - GPE, etc) couldn't collapse
- Only ALL GPE could toggle, others were stuck expanded

ROOT CAUSE:
- CSS selector was wrong: used + (adjacent sibling) instead of ~ (general sibling)
- JavaScript logic was weak for individual groups

FIXES APPLIED:

1. CSS Change (Line 121-123)
   Before: .tree-parent.open + .tree-children { display: block; }
   After:  .tree-parent.open ~ .tree-children { display: block !important; }
   
   Why: The .tree-children is inside <li>, not next to .tree-parent
   So ~ (finds any following sibling) works, + (only immediate) doesn't

2. JavaScript Enhancement (Line 622-640)
   Added:
   - Better click detection (don't toggle if checkbox clicked)
   - Direct jQuery show/hide for reliability
   - Smooth slideDown/slideUp animation (200ms)
   - Works for ALL groups, not just parent

3. Filter Logic Update (Line ~830-840)
   Added:
   - Smart auto-expand when filter matches
   - Respects user's manual collapse/expand choice
   - Remembers state across filter changes
