PROBLEM
================================================================================

When applying Series/Location filters to the tree sidebar in Idle Monitor:
- The counter updated correctly (showed right number)
- But the tree groups remained visually visible
- Users couldn't see which groups were filtered

Example: Filter "HD 465" → Counter showed "45|45" but all groups still visible

================================================================================
ROOT CAUSE
================================================================================

jQuery's .show() and .hide() methods apply "display: block" by default.

But tree elements need different display values:
- <li> elements (groups/devices): display: list-item
- Flexbox containers: display: flex
- Generic containers: display: block

Using .show() on <li> elements broke the CSS rendering.

================================================================================
SOLUTION
================================================================================

File Modified:
  idle-monitor/resources/views/frontend/idle-alarm/index.blade.php
  Function: filterTreeBySeriesLocation() (lines 703-851)

Changes:
  1. Use explicit .css('display', value) instead of .show()/.hide()
  2. Set display: list-item for <li> elements (groups/devices)
  3. Set display: flex for flexbox containers (parent/child)
  4. Set display: none for hidden elements
  5. Use direct child selector > for accuracy
  6. Enhanced debug logging
