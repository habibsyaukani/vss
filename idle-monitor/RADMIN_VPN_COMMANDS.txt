================================================================================
TROUBLESHOOTING
================================================================================

Q: Error when pasting command?
A: Try Option B (Manual edit) instead

Q: Apache won't start after restart?
A: - Open httpd.conf again
  - Make sure line is exactly: Listen 0.0.0.0:80
  - No extra spaces or typos
  - Save, restart

Q: Still can't access from VPN?
A: - Verify VPN IP: 26.29.218.176 (correct?)
  - Check Windows Firewall (allow Apache)
  - Try: netsh advfirewall firewall add rule name="Apache" dir=in action=allow program="C:\laragon\bin\apache\httpd-2.4.54-win64-VS16\bin\httpd.exe" enable=yes

Q: How to check if Laragon Apache is listening on all interfaces?
A: Open CMD and type:
  netstat -ano | find "80"
  
  You should see: 0.0.0.0:80 or LISTENING
