DANGER: DO NOT RUN THESE COMMANDS
================================================================================

❌ NEVER RUN THESE (Will DELETE all data):

    php artisan migrate:fresh
    php artisan migrate:fresh --seed
    php artisan migrate:refresh --seed
    php artisan db:wipe
    php artisan db:seed (alone, without migrate:fresh)

❌ NEVER DO THIS:
    Drop database manually
    Delete table manually
    Truncate table

WHAT THESE COMMANDS DO:
- migrate:fresh         → DROP all tables + CREATE new ones (DATA LOST!)
- migrate:refresh       → Rollback + Re-run (DATA LOST!)
- db:wipe              → Delete entire database (DATA LOST!)

================================================================================

✅ SAFE COMMANDS TO USE
================================================================================

✅ Safe to run anytime:

    php artisan migrate
    This only runs NEW migrations that haven't been run yet
    Does NOT delete existing data
    Does NOT rollback anything

✅ Safe for development setup:

    RUN_WITH_LARAGON.bat
    (Uses migrate, not migrate:fresh)

✅ Safe for starting server:

    RUN_DASHBOARD.bat
    (Only starts server, doesn't touch database)

🚨 IF YOU ACCIDENTALLY DELETE DATA
================================================================================

Don't panic! Here's what to do:

1. STOP the server (Press Ctrl+C)
2. DON'T make any more changes
3. CHECK if you have a backup
4. If backup exists: restore it
5. If no backup: data is gone (sorry!)

Prevention:
   ✅ Backup database regularly
   ✅ Use version control (git)
   ✅ Test in development, not production
   ✅ Always review commands before running
   ✅ Never run commands you don't understand

📝 MIGRATION SAFETY GUIDE
================================================================================

Safe workflow:

Step 1: Create new migration
   Command: php artisan make:migration add_column_to_table
   Result: New file in database/migrations/

Step 2: Edit the migration file
   - Add UP method (what to do)
   - Add DOWN method (how to undo)
   
Step 3: Run it
   Command: php artisan migrate
   Result: Only new migrations run
   Data: PRESERVED ✅

Step 4: If there's a problem
   Command: php artisan migrate:rollback
   Result: Undoes the last migration
   Data: PRESERVED ✅
