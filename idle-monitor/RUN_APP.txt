METHOD 2: MANUAL SETUP (Step-by-Step)
──────────────────────────────────────

STEP 1: Install PHP (if not already installed)

Windows:
  a. Go to: https://windows.php.net/downloads/releases/
  b. Download: php-8.3.X-Win32-vs16-x64.zip (latest stable)
  c. Extract to: C:\php
  d. Edit C:\php\php.ini:
     - Uncomment: extension=pdo_mysql
     - Set: display_errors = On
  e. Add C:\php to Environment PATH:
     - Right-click "This PC" → Properties
     - Advanced system settings → Environment Variables
     - User variables → Path → New → C:\php
     - Click OK
  f. Restart Command Prompt / PowerShell
  g. Verify: php -v

Mac:
  brew install php

Linux (Ubuntu/Debian):
  sudo apt-get install php php-cli php-mysql

STEP 2: Setup Database

Open Command Prompt in project folder:
  cd g:\project\vss\idle-monitor
  
Run migrations with seed data:
  php artisan migrate --fresh --seed

Expected output:
  Migrated: ...
  Database seeded successfully!

STEP 3: Start Development Server

  php artisan serve

Expected output:
  Laravel development server started: http://127.0.0.1:8000
  
  Listening on http://127.0.0.1:8000
  Press Ctrl-C to quit

STEP 4: Open Browser

  http://localhost:8000

  Password: manager123

TROUBLESHOOTING
───────────────

Problem: "php: command not found"
Solution:
  1. Install PHP (see METHOD 2, STEP 1)
  2. Add PHP to PATH environment variable
  3. Restart PowerShell / Command Prompt
  4. Test: php -v

Problem: "SQLSTATE[HY000] [2002] No such file or directory"
Solution:
  1. Start MySQL/MariaDB service
  2. Check .env file for DB credentials
  3. Run: php artisan migrate

Problem: "Class 'PDO' not found"
Solution:
  1. Edit php.ini
  2. Uncomment: extension=pdo_mysql
  3. Restart PHP server

Problem: "Port 8000 already in use"
Solution:
  1. Use different port: php artisan serve --port=8001
  2. Or find & kill process using port 8000

Problem: Login not working
Solution:
  1. Check migrations ran: php artisan migrate:status
  2. Seed data: php artisan db:seed --class=InitialDataSeeder
  3. Check .env: APP_KEY is set
  4. Clear cache: php artisan cache:clear
