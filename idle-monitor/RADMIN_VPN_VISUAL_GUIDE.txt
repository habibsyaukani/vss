THE QUICK FIX (COPY-PASTE)
================================================================================

EASIEST WAY:

1. Press: WIN + R

   ┌─ Run Dialog ─────────────┐
   │ Open: _____________      │
   │ [Cancel] [OK]            │
   └──────────────────────────┘

2. Type: cmd
   Then press: Enter

   ┌─ Command Prompt ──────────────┐
   │ C:\Users\YourName>           │
   │                              │
   └──────────────────────────────┘

3. Copy paste this command:

───────────────────────────────────────────────────────────────
powershell -Command "
$file = 'C:\laragon\bin\apache\httpd-2.4.54-win64-VS16\conf\httpd.conf'
$content = Get-Content $file
$content = $content -replace 'Listen 127.0.0.1:80', 'Listen 0.0.0.0:80'
$content = $content -replace 'Listen localhost:80', 'Listen 0.0.0.0:80'
Set-Content $file $content
Write-Host 'httpd.conf updated successfully!'
"
───────────────────────────────────────────────────────────────

4. Right-click → Paste (or Ctrl+V)

5. Press: Enter

   Wait for message:
   ✓ httpd.conf updated successfully!

6. Close CMD (type: exit, press Enter)

7. Restart Laragon:

   ┌─ Laragon Window ──────────────┐
   │                              │
   │ Apache: started         80   │
   │ MySQL: started         3306  │
   │                              │
   │ [Stop] ← Click this          │
   │                              │
   └──────────────────────────────┘

   Wait 5 seconds...

   Then click [Start] button (or let it auto-start)

   ✓ Done!

THE MANUAL WAY (If copy-paste doesn't work)
================================================================================

STEP 1: OPEN APACHE CONFIG FILE

1. Press: WIN + R

   ┌─ Run Dialog ─────────────┐
   │ Open: _____________      │
   │ [Cancel] [OK]            │
   └──────────────────────────┘

2. Type this exact path:

   notepad C:\laragon\bin\apache\httpd-2.4.54-win64-VS16\conf\httpd.conf

3. Press: Enter

   Notepad opens with httpd.conf file

───────────────────────────────────────────────────────────────

STEP 2: FIND THE LINE TO CHANGE

1. Press: Ctrl+F (Find dialog opens)

   ┌─ Find ──────────────────┐
   │ Find: [Listen 127]      │
   │ [Find All] [Cancel]     │
   └─────────────────────────┘

2. Type: Listen 127.0.0.1:80

3. Press: Enter

   Notepad highlights the line

───────────────────────────────────────────────────────────────

STEP 3: EDIT THE LINE

You should see this line highlighted in yellow:

   ┌────────────────────────┐
   │ Listen 127.0.0.1:80 ← │
   │                        │
   │ This line              │
   └────────────────────────┘

CHANGE IT TO:

   ┌────────────────────────┐
   │ Listen 0.0.0.0:80  ← │
   │                        │
   │ Like this              │
   └────────────────────────┘

HOW TO EDIT:
1. Double-click on "127.0.0.1" to select it
2. Type: 0.0.0.0
3. Press: Escape (close Find dialog)

BEFORE:
┌──────────────────────────────┐
│ Listen 127.0.0.1:80          │
└──────────────────────────────┘
         ↓↓↓ CHANGE ↓↓↓
AFTER:
┌──────────────────────────────┐
│ Listen 0.0.0.0:80            │
└──────────────────────────────┘

───────────────────────────────────────────────────────────────

STEP 4: SAVE FILE

1. Press: Ctrl+S

   File saves

2. Close Notepad: Press Alt+F4

───────────────────────────────────────────────────────────────

2. Window opens:

   ┌─ Laragon ──────────────────┐

   │ [Stop] [Web] [Database]   │
   └────────────────────────────┘

================================================================================
TROUBLESHOOTING - IF SOMETHING GOES WRONG
================================================================================

PROBLEM: Apache won't start after restart

SOLUTION:
1. Open httpd.conf again
2. Check the line you edited
3. Make sure it says exactly: Listen 0.0.0.0:80
4. No typos, no extra spaces
5. Save file
6. Try restart Laragon again

───────────────────────────────────────────────────────────────

PROBLEM: Can't access from VPN (still no connection)

SOLUTION:
1. Verify VPN IP is correct: 26.29.218.176
2. Check Windows Firewall:
   - Press: WIN + S
   - Type: Firewall
   - Open: Windows Defender Firewall
   - Click: Allow app through firewall
   - Find: Apache, enable both Private and Public

3. Or in CMD, run this:
   netsh advfirewall firewall add rule name="Apache" dir=in action=allow program="C:\laragon\bin\apache\httpd-2.4.54-win64-VS16\bin\httpd.exe" enable=yes

───────────────────────────────────────────────────────────────

PROBLEM: Localhost is slow (takes 10+ seconds)

SOLUTION:
1. This is normal with "localhost"
2. Use 127.0.0.1:8000 instead (faster)
3. Or: Use VPN IP 26.29.218.176:8000 (also fast)

───────────────────────────────────────────────────────────────

PROBLEM: Error message in CMD

SOLUTION:
1. Try the manual method instead
2. Make sure file path is correct
3. Make sure you have permission to edit the file
4. Try running as Administrator (right-click CMD → Run as Administrator)
