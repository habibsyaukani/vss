═══════════════════════════════════════════════════════════════
COMMON ISSUES & SOLUTIONS
═══════════════════════════════════════════════════════════════

Issue: SSH connection refused
Solution: 
  - Check server is running: ping 10.2.2.18
  - Check SSH port: nmap 10.2.2.18 -p 22
  - Verify SSH credentials

Issue: Git clone failed
Solution:
  - Check GitHub repository is accessible
  - Check internet connection on server
  - Verify repository URL

Issue: Docker containers won't start
Solution:
  - Check Docker is running: systemctl status docker
  - Check logs: docker logs idle-monitor-mysql
  - Check ports are not in use: netstat -tulpn | grep 3306

Issue: Nginx returns 502 Bad Gateway
Solution:
  - Check PHP-FPM: systemctl status php8.1-fpm
  - Check socket: ls -la /var/run/php/
  - Restart services: systemctl restart php8.1-fpm nginx

Issue: Database connection error
Solution:
  - Verify .env DB credentials
  - Check MySQL is running: docker ps
  - Test connection: docker exec -it idle-monitor-mysql mysql -u idle_user -p

Issue: Queue worker not processing jobs
Solution:
  - Check service: systemctl status idle-monitor-queue
  - Check logs: journalctl -u idle-monitor-queue -n 50
  - Restart: systemctl restart idle-monitor-queue
