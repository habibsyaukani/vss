🔧 COMMON COMMANDS ON SERVER
==============================

SSH to server:
   ssh root@10.2.2.18

Check services:
   systemctl status nginx
   systemctl status php8.1-fpm
   systemctl status idle-monitor-queue
   docker ps

View logs:
   tail -f /var/www/idle-monitor/storage/logs/laravel.log
   docker logs idle-monitor-mysql
   journalctl -u idle-monitor-queue -f

Restart services:
   systemctl restart nginx
   systemctl restart idle-monitor-queue
   docker-compose restart

Update application:
   cd /var/www/idle-monitor
   git pull origin main
   composer install --no-dev
   php artisan migrate --force
   php artisan cache:clear
   systemctl restart idle-monitor-queue

🆘 TROUBLESHOOTING
===================

Problem: Cannot SSH to server
Solution:
   - Check server is running: ping 10.2.2.18
   - Check SSH is enabled: telnet 10.2.2.18 22
   - Verify SSH credentials

Problem: Website not accessible
Solution:
   - Check Nginx: systemctl status nginx
   - Check firewall: ufw allow 80
   - Check application logs

Problem: Database connection error
Solution:
   - Check Docker: docker ps
   - Verify .env DB credentials
   - Check MySQL logs: docker logs idle-monitor-mysql
