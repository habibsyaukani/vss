COMMON ISSUES:
==============

Q: "Connection refused"
A: Laragon MySQL not running. Start Laragon in system tray.

Q: "Port 8000 already in use"
A: Another process using port 8000. Kill it or wait a minute.

Q: "Database error"
A: Make sure .env file is correct and MySQL is running.
