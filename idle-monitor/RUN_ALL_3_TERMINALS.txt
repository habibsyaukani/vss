================================================================================
WHAT'S HAPPENING IN BACKGROUND
================================================================================

Every 2 minutes (Terminal 2 scheduler + Terminal 3 queue):

  1. Scheduler check: "Is it time to run ImportAlarmJob?"
     → YES! Time: 2 min interval
     
  2. Queue dispatch: Send ImportAlarmJob to queue
     
  3. Queue worker (Terminal 3): Process job
     → Fetch data from Howen API
     → Save to alarm_raw table
     → Done!
     
  4. Check again in 5 min: ProcessIdleAlarmJob?
     → YES! Process alarms
     → Validate idle events
     → Save to idle_alarms table
     → Done!

Result: Data keeps flowing! ✓

================================================================================
TROUBLESHOOTING
================================================================================

Problem: Terminal 2 shows no output
Solution:
  1. Verify: php artisan schedule:work is running
  2. Check: .env file is correct
  3. Try: Press Enter to force output
  4. Try: Manual command: php artisan schedule:work

Problem: Terminal 3 shows error "No jobs available"
Solution:
  1. This is NORMAL - means no jobs to process yet
  2. Wait until Terminal 2 dispatches jobs
  3. Should see jobs appear after 2 minutes

Problem: Dashboard shows no new data
Solution:
  1. Check Terminal 2: Is scheduler running?
  2. Check Terminal 3: Is queue worker running?
  3. Check: Do you have Howen API credentials in .env?
  4. Check logs: storage/logs/laravel.log

Problem: "Port 8000 already in use"
Solution:
  1. Another process using 8000
  2. Kill it: netstat -ano | findstr :8000
  3. Or: Wait a minute and try again
  4. Or: Change port in artisan serve --port=8001

Problem: "Database connection error"
Solution:
  1. Check: Laragon MySQL running?
  2. Check: Database 'vss' exists?
  3. Check: .env DB_* settings correct?
  4. Try: php artisan migrate

================================================================================
BATTERY SAVER / MINIMIZE SYSTEM IMPACT
================================================================================

If running 3 terminals is heavy:

Option 1: Run only Terminal 1 + 2
  • Skip Terminal 3 (queue worker)
  • Scheduler will queue jobs
  • Jobs process on next queue:work run
  • Data pulling still works, just slower

Option 2: Reduce schedule frequency
  • Edit: app/Console/Kernel.php
  • Change: everyTwoMinutes() → everyFiveMinutes()
  • Less frequent pulling
  • Lower CPU usage

Option 3: Run in production mode
  • Use: supervisor to manage processes
  • Auto-restart on error
  • Professional setup
