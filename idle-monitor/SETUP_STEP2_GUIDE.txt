LANGKAH 2A: SETUP PHP KONFIGURASI
──────────────────────────────────

PHP membutuhkan extension MySQL untuk terhubung ke database.

OPSI 1: Gunakan Script (Otomatis)
─────────────────────────────────

1. Navigate ke project folder:
   cd g:\project\vss\idle-monitor

2. Jalankan setup script:
   setup_php.bat

   (Script ini akan):
   - Buka php.ini di C:\php
   - Uncomment MySQL extensions (pdo_mysql, mysql, mysqli)
   - Save php.ini
   - Backup php.ini.backup

3. Selesai!

═══════════════════════════════════════════════════════════════════════════════════

OPSI 2: Manual Setup (Jika script tidak bekerja)
────────────────────────────────────────────────

1. Buka file: C:\php\php.ini (dengan Notepad)

2. Cari baris berikut (biasanya di line ~900-950):
   
   ;extension=pdo_mysql
   ;extension=mysql
   ;extension=mysqli

3. Hilangkan semicolon (;) di depan:
   
   extension=pdo_mysql
   extension=mysql
   extension=mysqli

4. Save file (Ctrl+S)

5. Close Notepad

═══════════════════════════════════════════════════════════════════════════════════

LANGKAH 2B: SETUP DATABASE & SEED DATA
──────────────────────────────────────

Pastikan MySQL/MariaDB sudah RUNNING di system

1. Buka Command Prompt atau PowerShell

2. Navigate ke project:
   cd g:\project\vss\idle-monitor

3. Setup database:
   C:\php\php.exe artisan migrate --fresh --seed

   Ini akan:
   - Create semua database tables
   - Insert seed data (2 users, 6 device groups)
   - Create sample data

   Expected output:
   ✓ Migration: 2026_06_03_163708_create_devices_table
   ✓ Migration: 2026_06_03_163709_create_alarm_raw_table
   ... (lebih banyak migrations)
   ✓ Database seeded successfully!

4. Jika error "could not find driver":
   - Pastikan sudah uncomment extensions di php.ini
   - Restart Command Prompt
   - Try lagi: C:\php\php.exe artisan migrate --fresh --seed

TROUBLESHOOTING
───────────────

Problem 1: "could not find driver" error saat run migrate
Solution:
  1. Edit C:\php\php.ini manually
  2. Uncomment: extension=pdo_mysql
  3. Save file
  4. Restart Command Prompt
  5. Run migrate again

Problem 2: "Port 8000 already in use"
Solution:
  Use different port:
  C:\php\php.exe artisan serve --port=3001

Problem 3: "SQLSTATE[HY000] [2002] No such file or directory"
Solution:
  1. Make sure MySQL is running
  2. Check .env file:
     DB_HOST=127.0.0.1
     DB_PORT=3306
     DB_USERNAME=root
  3. Try migrate again

Problem 4: Database table tidak ada
Solution:
  1. Run migrations: C:\php\php.exe artisan migrate --fresh --seed
  2. Or reset: C:\php\php.exe artisan migrate:refresh --seed

Problem 5: Login tidak bekerja atau user not found
Solution:
  1. Check migrations ran successfully
  2. Run: C:\php\php.exe artisan db:seed --class=InitialDataSeeder
  3. Verify user exists: C:\php\php.exe artisan tinker
     User::all()
